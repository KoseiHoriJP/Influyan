# INFLU-ヤン (Influyan)

[English](README.md) | **日本語**

> 日本の関西地方を対象とする、一般向けインフルエンザ流行監視・予測アプリケーションの復元版プロトタイプです。予測モデルを組み込む前の段階のものです。

## プロジェクト概要

INFLU-ヤンは、地域ごとのインフルエンザの流行状況をわかりやすく伝える、一般向けの医療情報アプリケーションとして設計されました。公的な症例データ、地理的境界、予測グラフを組み合わせることで、流行の大きい地域を把握し、健康に関する判断や移動計画に応じた予防行動に役立てることを目指しています。

主な対象者は一般の利用者です。事前の操作トレーニングがなくても使えるよう、英語と日本語の両方に対応するインターフェースを設計しました。

## 当初構想していたシステム

プロジェクトの資料では、完成形のシステムに次の機能を想定していました。

- 厚生労働省（MHLW）および都道府県の感染症発生動向調査機関から、検証済みのインフルエンザデータを収集する。
- 公的データを毎週更新し、PDF、Excel、HTMLなど、形式の異なる配布ファイルを正規化する。
- 症例数と地理情報を組み合わせ、地域別に色分けしたコロプレスマップを作成する。
- 市区町村、感染症監視の地域区分、都道府県を、英語または日本語で検索できるようにする。
- 選択した地域の過去の統計と、インフルエンザ流行の予測傾向を表示する。
- 感染が集中する地域の把握や、地域差の理解を支援する。
- 将来的な個人のリスク評価や、環境要因との相関分析に対応する。

最終報告書では、都道府県の公的情報源は安定して毎週更新されるため、優先して採用したと説明されています。病院のデータや `disease.sh` も調査しましたが、最終的なデータソースには採用していません。

## 復元版プロトタイプの機能

このリポジトリのファイルでは、当初の構想のうち、次の部分を確認できます。

- 大阪、京都、奈良を対象とするインタラクティブな地図。
- 地域別の症例数に応じた色分け。
- 市区町村、感染症監視の地域区分、都道府県の選択。
- 市区町村および地域の検索。
- 選択した地域の詳細と症例数の表示。
- 英語・日本語の表示切り替え。
- 地域ごとの予測画像の表示。
- 症例データと予測データを提供するFlaskのJSONエンドポイント。

この復元版で使用する症例数と予測画像はプレースホルダーです。実際の最新の流行監視データや、学習済み予測モデルの出力ではありません。

## データと地理的な対象範囲

当初のソフトウェア要求仕様書（SRS）では、京都、大阪、兵庫、奈良、滋賀を対象とする公開地図を提案していました。データ取り込みの要件では、和歌山についても検討しています。復元版プロトタイプに含まれる地理的なオーバーレイは、大阪、京都、奈良のみです。

最終的なプロジェクト作業には、市区町村と公的なインフルエンザ監視地域との対応関係の調査も含まれていました。これらの監視地域は、通常の行政区分と必ずしも一致しません。また、同じ地名が複数の場所で使われる場合には、個別の対応が必要でした。たとえば、`北区`（`Kita-ku`）は大阪市と堺市の両方にあります。GeoPandasで正しく区別できるよう、チームは曖昧な名称を再定義しました。

## 資料に記載されたシステムの処理手順

当初の資料では、次の処理手順を想定していました。

1. Excel、PDF、HTMLで公開される週次の公的データを、ダウンロードまたはスクレイピングする。
2. 都道府県ごとに異なるデータ形式を整理、変換、検証、正規化する。
3. 処理済みデータを共有のデータストアに保存し、時期、年齢層、監視地域ごとに集計する。
4. GeoPandasを用いて、地域別の症例数を地理的境界と対応付ける。
5. インタラクティブなコロプレスマップと過去の統計を表示する。
6. 時系列予測を適用し、選択した地域の予測グラフを表示する。

最終報告書では、データ収集と正規化、GeoPandasによる地域分類、コロプレスマップの準備、英語・日本語での検索に取り組んだことが確認できます。以下に示すほかの構成要素には、SRSに記載されていても、このリポジトリには含まれていないものがあります。

## 計画されていたが、このリポジトリには含まれない機能

当初のSRSには、完成を確認できず、このリポジトリにも含まれていない次の要件があります。

- 公的情報源からの週次データの自動取り込み。
- 週・月・年単位を切り替えられる履歴表示。
- 実際のデータに基づくARIMA予測と、予測期間の調整。
- 複数地域の比較と、しきい値に基づくアラート。
- 健康状態、所在地、交通手段などを考慮した、個人のインフルエンザ感染リスク評価。
- 兵庫、滋賀、和歌山のデータと地理情報への対応。
- 人口密度による補正。
- 気温、大気質、湿度を用いた環境相関分析。
- ピアソン相関の可視化、折れ線グラフ、散布図。

## プロジェクトのファイル

- `app.py`：Flaskサーバー、エンドポイント、ダミーの症例データ、予測画像との対応付け。

- `create_dummy_plots.py`：プレースホルダーの予測画像を作成するスクリプト。
- `DemoVideo_Influyan.mp4`：元のファイルが失われる前の、完成版システムのデモ動画。

## 復元版プロトタイプの起動方法

Python 3が必要です。

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install Flask Pillow
python app.py
```

Flaskの開発用サーバーは通常、`http://127.0.0.1:5000` で起動します。

## 現在の制約

このリポジトリには、元のデータベース、公的データの処理パイプライン、予測モデル、モデル学習用コード、リスク評価機能、および完成版アプリケーションのその他の部分は含まれていません。

復元版のフロントエンドには、開発環境固有のlocalhostアドレスやプライベートIPアドレスも残っています。また、静的ファイル用のルートがFlaskの標準の静的ファイルルートと競合しており、ForecastとRisk Assessmentのナビゲーションリンクに対応するFlaskのルートもありません。復元版をブラウザーで完全に動作させるには、これらの問題の修正が必要になる場合があります。

残っている報告資料には、予測精度のスコア、評価用データセット、その他の定量的なモデル評価結果が記載されていません。そのため、ここではモデル性能についての主張はしていません。
